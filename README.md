# Study Time Calculator 📚

## About the Project
The Study Time Calculator is a simple Python project that helps students track their daily study hours and monitor their progress toward their study goals.

## Features
- Set a daily study goal.
- Enter the number of subjects and study hours for each subject.
- Calculate total study time.
- Calculate average study time per subject.
- Display daily progress as a percentage.
- Show the remaining study time needed to achieve the goal.
- Notify the user when the daily goal is completed or exceeded.

## Technologies Used
- Python 3

## How It Works
1. Enter your daily study goal in hours.
2. Enter the number of subjects you studied.
3. Enter each subject's name and study duration.
4. View your study report, including total hours, average time, daily progress, and remaining time.

## Example Output
```text
===== STUDY REPORT =====
Total study time: 3.0 hours
Average study time: 1.5 hours
Daily progress: 60.0 %
Study time remaining: 2.0 hours
```

## Concepts Used

- User input and output
- For loops
- If-elif-else statements
- Arithmetic operations
- Percentage calculations

This project was created to practise Python programming while building a useful tool for managing daily study goals and improving time management.
