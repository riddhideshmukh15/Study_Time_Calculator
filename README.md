# 📚 Study Time Calculator

A simple Python beginner project that calculates the **total study time** and **average study time** for multiple subjects.

## ✨ Features

* Takes the number of subjects as input
* Takes study time for each subject
* Calculates total study time
* Calculates average study time
* Beginner-friendly Python code

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Command Prompt or VS Code.
3. Run:

```bash
python study_time_calculator.py
```

4. Enter the required study time for each subject.

## 📌 Example

```text
===== STUDY TIME CALCULATOR =====

Enter number of subjects: 3
Enter study time for subject 1 (hours): 2
Enter study time for subject 2 (hours): 1.5
Enter study time for subject 3 (hours): 2

Total study time: 5.5 hours
Average study time: 1.8333333333333333 hours
```
