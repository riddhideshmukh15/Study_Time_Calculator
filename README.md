# 📚 Study Time Calculator

A simple Python beginner project that calculates total and average study time and checks progress toward a daily study goal.

## Features

* Enter a daily study goal
* Enter the number of subjects
* Enter subject names
* Enter study time for each subject
* Calculate total study time
* Calculate average study time
* Show remaining study time
* Show when the daily goal is completed or exceeded

## Technologies Used

* Python

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or Terminal.
3. Run:

```bash
python study_time_calculator.py
```

4. Enter your study goal, subjects, and study hours.

## Example

```text
===== STUDY TIME CALCULATOR =====

Enter your daily study goal (hours): 6
Enter number of subjects: 3

Enter subject 1 name: Maths
Enter study time for Maths (hours): 2

Enter subject 2 name: Physics
Enter study time for Physics (hours): 1.5

Enter subject 3 name: Python
Enter study time for Python (hours): 2

===== RESULT =====
Total study time: 5.5 hours
Average study time: 1.83 hours
Study time remaining: 0.5 hours
```
